# Shoaib Ahmed — Websites

All of Shoaib Ahmed's public websites in one place, ready for **GitHub Pages**.

## Live structure (once Pages is enabled)
- `/` — Link hub: every website in one list
- `/store/` — Shoaib Ahmed — Store (food, shoes, clothing, makeup, salon)
- `/anime/` — Anime edits website

## Social-media link previews
Every page carries Open Graph + Twitter Card tags and a custom 1200×630
preview image (in `assets/`), so when a link is shared on Facebook,
WhatsApp, LinkedIn or X it shows a rich preview card — title,
description and image — instead of a bare link.

## Publishing
1. Push this repo to GitHub as `shoaib-websites` (account: pyblitz).
2. Repo Settings → Pages → Source: deploy from branch `main`, folder `/ (root)`.
3. Site goes live at https://pyblitz.github.io/shoaib-websites/

Note: back-end systems (order-saving admin panels) run on their own
hosting and are not part of this static Pages repo.
